EAST FORK LEAD RADAR
=====================
Phone-first PWA dashboard for East Fork Industrial Services.

CURRENT VERSION
- Contains the latest opportunity dataset supplied in this conversation.
- Filter by HOT/WARM/WATCH.
- Search by company, city, project, address, or scope.
- One-tap call, email (when an email is available), and website.
- No CRM and no account required.

ANDROID INSTALL
1. Put this folder on a web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the site's index.html URL in Chrome on Android.
3. Chrome menu -> Add to Home screen / Install app.

IMPORTANT
This static version is the phone interface. The daily ChatGPT opportunity automation remains the source of new leads. A production version can connect the dashboard to a live database/API so new leads appear automatically without republishing the app.
